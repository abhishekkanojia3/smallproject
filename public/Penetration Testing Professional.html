Course Overview

Our Penetration Testing Professional programme is meticulously designed to align with the OSCP (Offensive Security Certified Professional) certification. This intensive 12-week course combines theoretical knowledge with extensive hands-on practice, preparing you to identify, exploit, and report security vulnerabilities in real-world environments. Comprehensive Syllabus

1
Penetration Testing Fundamentals
Penetration testing methodology and frameworks (PTES, OWASP), reconnaissance techniques (passive and active), enumeration strategies, information gathering with OSINT tools, scanning and vulnerability assessment
2
Linux & Windows Exploitation
Buffer overflow exploitation (stack and heap), privilege escalation techniques (Linux and Windows), exploit development basics, shellcode creation, return-oriented programming (ROP), bypassing DEP and ASLR
3
Web Application Security
OWASP Top 10 vulnerabilities, SQL injection (manual and automated), cross-site scripting (XSS), authentication and session management flaws, file upload vulnerabilities, command injection, SSRF, XXE
4
Network Penetration Testing
Active Directory enumeration and attacks, Kerberos exploitation (Kerberoasting, Golden/Silver tickets), lateral movement techniques, pivoting and port forwarding, password cracking, post-exploitation frameworks
5
Advanced Exploitation & OSCP Prep
Client-side attacks, antivirus evasion techniques, custom exploit development, report writing and documentation, OSCP exam strategies, 24-hour practical exam simulation, capstone penetration testing project
